# Module 03: NLP, Tokenization & Embeddings

## Objective

Answer the questions: **"Why tokens? Why embeddings? How does semantic search work?"**

After this module, you should understand the text processing pipeline and how meaning is represented as vectors.

## Prerequisites

- [Module 01: How LLMs Work](../01-how-llms-work/)
- [Module 02: Training & Learning](../02-training-and-learning/)

| 03 | [Semantic Similarity](./03-semantic-similarity.md) | Cosine similarity and vector search |

## Checkpoint

After completing this module, you should be able to:

- [ ] Explain why we use subword tokenization instead of words or characters
- [ ] Describe BPE (Byte Pair Encoding) algorithm at a high level
- [ ] Explain what an embedding represents
- [ ] Calculate cosine similarity between two vectors
- [ ] Describe how semantic search / RAG retrieval works
