# Module 04: RAG & System Design

## Objective

Answer the question: **"How do I build production AI systems?"**

After this module, you should understand how to architect real-world LLM applications, when to use RAG vs fine-tuning, and common production patterns.

## Prerequisites

- [Module 01-03](../01-how-llms-work/) completed
- Basic understanding of web services/APIs

## Topics

| # | Topic | Description |
|---|-------|-------------|
| 01 | [RAG Fundamentals](./01-rag-fundamentals.md) | Retrieval-Augmented Generation explained |
| 02 | [RAG vs Fine-tuning](./02-rag-vs-finetuning.md) | When to use which approach |
| 03 | [Production Architecture](./03-production-architecture.md) | Patterns for real-world systems |

## Checkpoint

After completing this module, you should be able to:

- [ ] Explain the RAG pipeline end-to-end
- [ ] Decide when to use RAG vs fine-tuning for a given use case
- [ ] Describe common production concerns (latency, cost, caching)
- [ ] Design a basic LLM system architecture
- [ ] Identify failure modes and mitigation strategies
