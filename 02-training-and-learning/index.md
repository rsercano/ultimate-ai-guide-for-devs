
# Module 02: Training & Learning

## Objective

Answer the question: **"How does a model actually learn?"**

After this module, you should have an intuitive but mechanically accurate understanding of how neural networks improve through training.

## Prerequisites

- [Module 01: How LLMs Work](../01-how-llms-work/)
- Basic understanding of functions and derivatives (high school level)

## Topics

| # | Topic | Description |
|---|-------|-------------|
| 01 | [Neural Network Basics](./01-neural-network-basics.md) | Neurons, layers, and forward pass |
| 02 | [Loss and Backpropagation](./02-loss-and-backprop.md) | How errors guide learning |
| 03 | [Optimization and Regularization](./03-optimization-and-regularization.md) | Learning rate, Adam, overfitting |

## Checkpoint

After completing this module, you should be able to:

- [ ] Explain what a loss function measures
- [ ] Describe backpropagation in simple terms
- [ ] Explain why learning rate matters
- [ ] Describe overfitting and how to prevent it
- [ ] Understand why we need validation sets
