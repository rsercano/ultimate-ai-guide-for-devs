# Module 05: Prompting, Tools & Evaluation

## Objective

Answer the questions: **"How do I control LLMs effectively? How do I test them?"**

After this module, you should understand prompt engineering, tool/function calling, and how to evaluate LLM systems.

## Prerequisites

- [Modules 01-04](../01-how-llms-work/) completed
- Some hands-on experience with LLM APIs helpful

## Topics

| # | Topic | Description |
|---|-------|-------------|
| 01 | [Prompt Engineering](./01-prompt-engineering.md) | Techniques for better prompts |
| 02 | [Tool Calling & Agents](./02-tool-calling-agents.md) | Giving LLMs abilities to act |
| 03 | [Evaluation Strategies](./03-evaluation-strategies.md) | Measuring LLM performance |

## Checkpoint

After completing this module, you should be able to:

- [ ] Apply common prompting techniques (few-shot, CoT, etc.)
- [ ] Implement function/tool calling with any major API
- [ ] Design an agent loop with tool use
- [ ] Set up an evaluation pipeline for LLM outputs
- [ ] Choose appropriate metrics for different tasks
