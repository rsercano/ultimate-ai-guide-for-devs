# Contributing

Contributions are welcome! Here's how you can help:

## Ways to Contribute

### Content
- Fix typos or clarify explanations
- Add new resources with annotations
- Translate content to other languages
- Add diagrams or visual explanations

### Structure
- Suggest reorganization if something feels out of place
- Propose new modules or topics

## Guidelines

1. **Keep it practical** — This is for developers, not researchers
2. **Cite sources** — Every claim should have a reference
3. **Follow the format** — Check existing files for structure
4. **No fluff** — If it doesn't help understanding, remove it

## Pull Request Process

1. Fork the repository
2. Create a branch (`git checkout -b fix/typo-in-attention`)
3. Make your changes
4. Submit a PR with a clear description

## Code of Conduct

Be respectful. We're all learning here.
